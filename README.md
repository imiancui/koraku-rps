# 狐樂・絆之勝負

使用原生 HTML、CSS 與 ES Modules 製作的模組化網頁小遊戲。玩家每 5 秒與狐娘小樂猜拳；敗勢會進入八方向 QTE，成功即可反制。遊戲包含道具、變拳技能、經驗升等、能力分配、四階關卡、商店、泳裝事件與蒙眼切西瓜。

## 啟動

本遊戲支援多種啟動方式：

1. **直接開啟**：直接以瀏覽器開啟 [index.html](file:///d:/game-dev/New-game-project-4/index.html) 即可暢玩（免開伺服器，支援本機 `file://` 協議）。
2. **一鍵啟動（Windows）**：雙擊執行 [啟動遊戲.bat](file:///d:/game-dev/New-game-project-4/啟動遊戲.bat)。
3. **開發伺服器**（需求 Node.js 18+）：
   ```bash
   npm run dev
   ```
   瀏覽器開啟 http://127.0.0.1:4173/ 。專案零第三方套件依賴，不需要先安裝 npm packages。

在 Tailscale 網路上給其他裝置玩（iPhone／iPad／另一台電腦）：

    npm run start:tailscale

本機需已登入 Tailscale。指令會把遊戲掛到 MagicDNS 的 HTTPS（僅同一個 tailnet 可開）。網址會印在終端機，形如：

    https://20250606-120834.tailfe8b74.ts.net/

備用 HTTP：`http://100.94.165.47:4173`。第一要在 tailnet 後台開通 Serve；之後重跑這條指令就會自動掛上。

執行規則測試：

    npm test

## 操作

- 出拳：點擊石頭／布／剪刀，或按 1／2／3
- 變拳：看見雙方出拳後的 1 秒內點擊「変」，或按 F；消耗 25 MP
- QTE：斜向需同時按兩個正方向，例如 W＋D 或 ↑＋→；也保留 Q／E／Z／C 快捷鍵
- 道具：戰鬥左下快捷欄
- 切西瓜：點擊「就是現在」，或按空白鍵；固定切 3 刀，每次切中在三刀結算時額外給予 100 EXP

## 模組結構

    src/
    ├─ js/
    │  ├─ config/       # 關卡、手勢、道具與平衡數值
    │  ├─ core/         # 事件匯流排、存檔狀態、計時器
    │  ├─ services/     # localStorage 持久化
    │  ├─ systems/      # 戰鬥、QTE、成長、戰後事件、音效
    │  └─ ui/           # DOM 畫面與 AVG 對話控制
    └─ styles/
       ├─ tokens.css    # 色彩、字體與共用設計變數
       ├─ base.css      # 全域骨架
       ├─ components.css
       ├─ screens.css
       ├─ animations.css
       └─ responsive.css

EventBus 將規則層和 UI 解耦；日後若加入多人同步，可用網路服務接收／發送戰鬥事件，不必把連線邏輯寫進畫面元件。

## 關卡與成長

| 章節 | 小樂 HP | 需求等級 | 造型 |
|---|---:|---:|---|
| 初逢・朱鳥居 | 1,000 | 1 | 預設 |
| 夕映・狐火 | 2,000 | 3 | 預設 |
| 月下・九尾試 | 5,000 | 6 | 預設 |
| 鏡界・白金小樂 | 10,000 | 10 | 2P 色 |

- 基礎 HP 100、MP 50、傷害 10
- 每次升等獲得 5 SP
- 生命每點增加 10 HP；魔力每點增加 10 MP；攻擊每點增加 5 傷害
- 勝利獲得 100 星砂，敗北獲得 50 星砂
- HP／MP 藥水各售 100 星砂，恢復 25 點

## 開發測試

在網址加上 ?debug=1 會顯示小型 DEV 面板，可快速觸發勝利、敗北或 Lv.10 狀態，用來回歸測試戰後事件與最終 Boss；正常網址不會載入這些控制項。
